# M. Muhammed Haji & Ayishabi Wedding Invitation

A digital wedding invitation for the wedding of Fathimath Famnaz & Mohammed Sakeeb. Guests tap an animated envelope to open the invitation card, and background music starts playing.

Built with React, TypeScript, Vite, Tailwind CSS and Framer Motion.

## Getting Started

```bash
npm install
npm run dev     # start the dev server
npm run build   # production build in dist/
```
